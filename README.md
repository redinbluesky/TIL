## 🔄 자동화 워크플로우

```
[메모 등록 (Issue)]
        │
        ▼
[AI 정제 — 사실 검증 + Markdown 초안 생성]
        │
        ▼
[인간 검토 (Pull Request Review)]
        │
        ▼
[자동 커밋 + README 인덱스 업데이트]
```

| 단계 | 설명 |
|------|------|
| 📝 **메모 감지** | Issue 템플릿으로 학습 메모를 자유 형식으로 등록합니다. |
| 🤖 **AI 정제** | AI 에이전트가 기술적 사실을 검증하고 표준 Markdown 초안을 생성합니다. |
| 👤 **인간 검토** | Pull Request를 통해 내용의 진실성과 정확성을 직접 검토·수정합니다. |
| ✅ **자동 기록** | 승인된 문서만 저장소에 커밋되며 이 README 인덱스가 자동 업데이트됩니다. |
