# Hermes를 활용한 디자인 시스템 기반 로그인 페이지 구축

## Context

Codex에서 생성한 디자인 MD 파일과 작업명세서를 Hermes로 가져와 로그인 페이지 HTML 구성. Codex에서 구성한 파일과 90%의 유사도 검증.

## Core

### 작업명세서 기반 구축

- Codex에서 생성한 작업명세서 가져오기
- WANTED Design System 참조하여 로그인 HTML 구성
- Hermes에서 페이지 구축

### 유사도 검증

- Codex 결과 vs Hermes 결과 비교
- 90% 유사도 확인

## Insight

- Codex(디자인+명세서) → Hermes(구축) 역할분배가 효율적
- 크레딧 소모 문제 해결
- 하이브리드 워크플로우 확정
