# Hermes를 활용한 디자인 시스템 기반 로그인 페이지 구축

## 학습 시작

Codex가 추출한 Figma WANTED Design System의 디자인 토큰을 바탕으로, Hermes를 사용하여 로그인 페이지 HTML을 구축하는 방법을 학습했습니다. Codex 결과와 Hermes 결과를 비교하여 90% 유사도를 확인했고, 두 도구의 역할분배 방식을 결정했습니다.

## 학습 과정

### 1. 작업명세서 작성

- 디자인 MD 파일을 생성하여 WANTED Design System의 구조를 정리했습니다.
- 로그인 페이지 HTML을 구성하기 위한 작업명세서를 작성했습니다.
- 작업명서에는 색상, 타이포그래피, 스페이싱 등 디자인 토큰을 반영했습니다.

### 2. 로그인 HTML 구축

- Hermes를 사용하여 작업명세서대로 로그인 페이지 HTML을 작성했습니다.
- Codex가 생성한 결과와 비교했을 때 90% 정도의 유사도를 확인했습니다.
- 디자인 토큰을 그대로 반영하여 일관된 UI를 구현했습니다.

## 학습 결과

- Codex 결과와 Hermes 결과 간 90% 유사도 검증 완료
- 두 도구 간 역할분배 방식 확정

- 향후 동일한 디자인 시스템 기반 페이지 구축 시 이 워크플로우 적용
