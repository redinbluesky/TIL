# 2026-08-18-Codext-Figma-Design-System-to-Code-Workflow.md
## Context
Figma Community의 디자인 시스템을 기반으로 Codex를 활용하여 디자인 명세(`design.md`)와 Hermes Skill을 자동 생성하고, 이를 통해 실제 UI(로그인 페이지)를 구현하는 워크플로우 검증.

## Core
1. **Design Extraction**: Figma Community에서 디자인 시스템(Tokens, Styles) 추출.
2. **System Definition**: 추출된 정보를 바탕으로 `design.md` 작성 및 Hermes Skill로 등록.
3. **Automated Implementation**: Codex를 호출하여 `design.md`의 규칙을 준수하는 UI 컴포넌트(Login Page) 생성.
4. **Verification**: 생성된 UI가 디자인 시안의 속성(Color, Spacing, Typography)을 정확히 반영하는지 확인.

## Insight
- 디자인 시스템을 '코드'가 아닌 '에이전트가 이해할 수 있는 명세(System)'로 변환하는 것이 자동화의 핵심.
- Design Tokens $\rightarrow$ Design Spec (`design.md`) $\rightarrow$ Agent Skill $\rightarrow$ Code 구현으로 이어지는 파이프라인 구축.
